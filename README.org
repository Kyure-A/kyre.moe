* kyre.moe

Personal website and blog built with rshono (Hono, Rspack and React Server Components), statically rendered for GitHub Pages.

** Screen Shot
[[file:./screenshot.png]]

** Highlights

- rshono generates static HTML and Flight data for every public route
- React powers controls and Home animation; Panda CSS provides styles
- A static Flight adapter supports client navigation on GitHub Pages

** Dev

Node.js 26 or newer is required. The Nix shell and CI use Node.js 26; content preparation runs TypeScript directly with Node's built-in type stripping.

#+begin_src bash
  nix develop
  pnpm install
  pnpm dev
#+end_src

The rshono development server renders routes with React Server Components. It watches articles and regenerates content when they change. =pnpm dev -- --port 3001= chooses another port.

** Content helpers

#+begin_src bash
  pnpm content
#+end_src

Org articles are exported to Markdown and rendered to per-article JSON. OGP images, sitemap.xml, robots.txt, and the prerender route list are generated by =pnpm content=. Takumi renders OGP images directly from plain layout nodes, using its native PNG renderer. OGP generation is independent of the React application. Set =OG_IMAGE_FONT_PATH= to a Japanese font when no supported system font is available; GitHub Actions downloads Noto Sans JP.

** Build and verify

#+begin_src bash
  pnpm build
  pnpm typecheck
  pnpm check:static
  pnpm lint
  pnpm start
#+end_src

The static site is emitted to =dist/client=. =pnpm start= serves those files locally; no application server is required in production. GitHub Actions builds and deploys that directory to GitHub Pages.

Client navigation fetches static Flight data through the GitHub Pages adapter and updates the React page, metadata and document language. The controls and Home background stay mounted. Native View Transitions morph blog titles and descriptions, including Back/Forward with scroll restoration. Fetching completes before the transition starts. Reduced motion and browsers without the API skip the animation; links also work without JavaScript.

With =pnpm start= running, =pnpm check:transitions= verifies actual shared-element animation geometry, history scroll restoration, delayed Flight responses, reduced motion, API fallback, and hash links. Set =BASE_URL=http://localhost:3000= to check =pnpm dev= instead. On macOS it uses installed Chrome; elsewhere provide =CHROME_EXECUTABLE= or an installed Playwright Chromium. =PLAYWRIGHT_MODULE_PATH= can point to another local directory containing =playwright-core=.

=pnpm check:interactions= also checks theme persistence, language and metadata, code copying, live age, keyboard navigation through the Home dock, persistent Home background and controls, 404 recovery and delayed hash-history navigation. Component interaction checks run against the actual site.

=pnpm build:framework= runs only the rshono build and static output finalization, using the already generated content and Panda snapshot. It skips content preparation.
